# ❤️ Heart Disease Prediction & Cardiac Risk Analytics System

## 📌 Overview

The **Heart Disease Prediction & Cardiac Risk Analytics System** is a healthcare analytics project designed to analyze patient health parameters and provide a cardiac risk assessment.

The system combines **Data Analytics, Machine Learning concepts, and an interactive dashboard** to help visualize cardiac risk patterns based on factors such as age, blood pressure, cholesterol, chest pain, heart rate, and exercise-induced angina.

## 🎯 Objectives

* Analyze patient health data for cardiac risk patterns.
* Provide an interactive cardiac risk prediction interface.
* Visualize risk distribution using charts and graphs.
* Analyze risk across different age groups and genders.
* Identify important cardiac risk indicators.
* Display patient-level risk information in an easy-to-understand dashboard.

## 🛠️ Technologies Used

* **HTML5** – Dashboard structure
* **CSS3** – User interface and responsive design
* **JavaScript** – Prediction logic and dashboard functionality
* **Chart.js** – Data visualization
* **Machine Learning** – Cardiac risk prediction concept
* **CSV Data** – Patient record analytics

## 📊 Dashboard Features

### 1. Patient Prediction

Users can enter patient information including:

* Age
* Gender
* Resting Blood Pressure
* Cholesterol
* Chest Pain Type
* Maximum Heart Rate
* Fasting Blood Sugar
* Exercise-Induced Angina

The system generates a cardiac risk score and classifies it as:

* 🟢 Low Risk
* 🟠 Moderate Risk
* 🔴 High Risk

### 2. Data Analytics

The dashboard provides visualizations for:

* Risk Distribution
* Gender Distribution
* Cardiac Risk by Age Group
* Important Risk Indicators
* Patient Risk Overview

### 3. Patient Records

Patient information can be displayed with:

* Patient ID
* Age
* Gender
* Blood Pressure
* Cholesterol
* Risk Score
* Risk Status

## 🔄 Data Processing

The system represents categorical patient information numerically. For example:

* Gender: Male = 1, Female = 0
* Chest Pain Type: 0–3
* Fasting Blood Sugar: Normal = 0, High = 1
* Exercise-Induced Angina: No = 0, Yes = 1

The data can then be analyzed to identify patterns and risk indicators.

## 📈 Analytics

The dashboard helps understand relationships between patient characteristics and cardiac risk, particularly:

* Increasing risk across age groups
* Blood pressure levels
* Cholesterol levels
* Chest pain type
* Exercise-induced angina
* Heart rate

## ⚠️ Project Status

This project currently contains a **prototype/demo risk-scoring implementation**. The prediction function is designed to be replaced by a trained Machine Learning model in the final implementation.

Therefore, the displayed risk score should be treated as a **project demonstration and not as a medical diagnosis**.
